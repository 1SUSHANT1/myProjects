About the Website

This website is my personal collection of projects, experiments, documentation, and things I have learned while working with computers.
Everything here is done in my own time and of my own free will. Nothing on this website is school work. Some projects started simply because I was curious about something, while others grew into much larger experiments than I originally expected. If you read one project, there is probably another one which naturally follows.
A lot of my work revolves around Linux, software development, web infrastructure, networking, and cybersecurity. I like learning by building, which means writing programs, configuring servers, breaking things, figuring out what went wrong, fixing them, and documenting the process.
You will find a variety of things on this website, including software projects, game development, Linux and server projects, security assessments, networking and DNS configuration, and technical documentation.
Also, if you think the website looks fugly, I am currently working on that.

How I Document things

My main focus is on learning, understanding and teaching. I approach my projects with the same attention to detail I would expect from professional work, but I document them my way. That means I don't just show the finished result. I like documenting what I tried, what broke, why it broke, and how I eventually figured it out.

If something takes three hours because I spent two of them looking in completely the wrong place, that's part of the story too. Hopefully it saves someone else the two hours.

About the Server

This website is being served by an Apache server running on an old Redmi Note 10 pro. The phone could no longer be used as a phone, so I decided to repurpose it as a web server.
It runs Alpine Linux through postmarketOS and hosts this website from my home. Read more about this here: Repurposing My Old Phone

The Ecosystem

This might not be explicitly mentioned in the individual projects, but here is a brief overview of the environment I use to build, administer, test, and host everything.

  • My production server, an old Redmi Note 10 pro runs Alpine Linux.
  • My standby backup server, an old HP Pavilion laptop runs Debian. It is configured to take over if my production server goes down.
  • My laptop, which I use to administer my servers, runs Ubuntu.
  • My attack machine, which I use for penetration testing and security assessments, runs Kali Linux.
